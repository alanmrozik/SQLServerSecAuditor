# SQLServerSecAuditor

This app is ours Bachelor's thesis for University of Technology of Poznan 2026 AD.

App is written in C# with WPF framework. You can use it to perform security audit for your local or remote SQL Server instances. App provices also:
-scoring,
-snapshots (save and compare),
- PDF reports.

T-SQL scripts are provided from CIS Benchmark for SQL Server 2022.
